# Project Plan

-----

## What is this?

This application is a classic game of sudoku.

## What is the MVP?

The minimal viable product is a CLI text-based 
sudoku game that provides
an initial board setup and allows the player to 
input numbers to find a solution.

## What are the nice to haves?

The nice to haves for this project are:
a sudoku api integration, implementation of
Norvig's paper on sudoku, and a gui to play the game.

## When will the project be complete?

The project will be complete once the MVP and
nice to haves have been fully implemented.
